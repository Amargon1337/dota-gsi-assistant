# 🛡️ Dota 2 GSI Tactical Assistant & AI Co-Pilot

Интерактивный тактический ассистент реального времени для Dota 2 с двухуровневой системой искусственного интеллекта:
1. **Laya (Система-1)** — локальная неавторегрессионная модель ([convaiinnovations/laya](https://huggingface.co/convaiinnovations/laya)) на базе ModernBERT-large (~35 мс на GPU), оценивающая риски ганга и микро-решения на лету.
2. **Google Gemini Flash Lite (Система-2)** — облачный стратегический AI-тренер с 9000 MMR (лимит **500 RPD** в Google AI Studio), проводящий разбор ошибок при гибели, расчет байбека и ситуативные билды.

100% безопасен для **VAC (Valve Anti-Cheat)** — работает через официальный HTTP GSI протокол движка Source 2.

---

## 🚀 Быстрый старт

### 1. Установка конфига в Dota 2
Конфиг уже автоматически установлен в папку игры:
`C:\Program Files (x86)\Steam\steamapps\common\dota 2 beta\game\dota\cfg\gamestate_integration\gamestate_integration_assistant.cfg`

*(Если Dota 2 запущена, введите в консоль `reload_gsiconfig`)*.

### 2. Запуск сервера ассистента
```powershell
cd c:\ag\dota-gsi-assistant
npm start
```

### 3. Открытие дашборда
* **На ПК (или 2-м мониторе):** откройте [http://localhost:3000](http://localhost:3000)
* **На смартфоне / планшете:** подключитесь к домашнему Wi-Fi и откройте адрес, указанный сервером в консоли (например, `http://192.168.x.x:3000`).

## 🤖 Настройка AI (Google Gemini + Laya)

### Настройка Gemini (500 RPD)
1. Получите бесплатный API ключ в [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Нажмите кнопку **«🤖 AI Настройки»** в правом верхнем углу дашборда.
3. Вставьте API ключ и выберите модель:
   * **`gemini-2.0-flash-lite`** (500 RPD — ультрабыстрый отклик)
   * **`gemini-2.5-flash-lite`** (500 RPD — сбалансированная модель)
   * **`gemini-3.5-flash-lite`** (экспериментальная модель)
   * или введите свое имя модели вручную.
4. Нажмите **«Сохранить настройки»**. Настройки сохраняются в `ai-config.json` и не сбрасываются при перезапуске.

### Запуск Laya System-1 (Локальный микросервис)
В отдельном окне терминала запустите:
```powershell
cd c:\ag\dota-gsi-assistant
npm run laya
```
Микросервис поднимется на порту `8000` (`http://127.0.0.1:8000/v1/systemone`) и начнет передавать сверхбыстрые решения по ганг-риску и макро-действиям. Если Laya не запущена, система автоматически использует встроенный эвристический фоллбек.

## 🎮 Как протестировать в лобби с ботами

1. Запустите Dota 2.
2. Перейдите в **Играть** -> **Пользовательские лобби** -> **Создать лобби** (или Одиночная игра с ботами).
3. Начните матч.
4. Откройте дашборд:
   * Вы увидите живой отсчет до рун, стаков крипов и смены дня/ночи.
   * Шкала **Gank Risk (Laya)** будет динамически расти в ночное время и при низком здоровье.
   * Если ваш герой погибнет, Gemini автоматически проанализирует причину смерти и озвучит голосовой совет на респаун прямо через браузер!
   * В любой момент нажмите кнопку **«⚡ Спросить совет сейчас»** или введите вопрос в поле ввода тренера.

## 🧪 Тестирование без запуска Доты (Демо-режим)
Нажмите кнопку **«🧪 Демо-режим»** в правом верхнем углу дашборда. Ассистент начнет симулировать матч с Juggernaut на 5-й минуте игры.
